# Painel de Rádio · versão de DEMONSTRAÇÃO

Todos os dados desta versão são **fictícios**, gerados por script só para testar e apresentar o painel
(bancos de jan–mar/2020 a jul–set/2026). As concorrentes têm nomes inventados (Atlântica FM, Onda Sul FM, Farol FM…).
O painel mostra uma faixa "Ambiente de demonstração" e os PDFs saem com a marca-d'água "DADOS FICTÍCIOS"
(chave `"demo": true` no `parametros.json`).

O código é o mesmo do painel real; muda só a pasta `dados/` e o `parametros.json`.
